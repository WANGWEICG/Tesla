# Tesla利息先繳方案-車貸試算器

一個Tesla / （利息先繳）車貸試算工具。

## 功能

- 支援自訂：
  - 車價
  - 頭期款
  - 利率
  - 貸款期數
- 自動計算：
  - 月付款
  - 總利息
  - 總成本
  

---

## 注意事項

本工具為「估算用途」。

計算邏輯主要依照 Tesla 台灣官網常見金融方案試算方式進行反推（利息先繳），並非銀行正式 APR 或本利平均攤還公式。

實際貸款內容可能因以下因素不同：

- 金融公司
- 專案優惠
- 手續費
- 保險
- 領牌費
- 綁約條件
- 提前清償條款

最終仍需以正式合約內容為準。
